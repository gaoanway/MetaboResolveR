# Phase 4 Task: Metabolism Manuscript

**Goal:** Generate a manuscript aimed first at `Metabolism`, using the package,
reference database, and local real-case validation as the core evidence.

**Primary Target Journal**

`Metabolism`

**Framing**

The manuscript should emphasize biological and translational value: improving
confidence in human plasma metabolite interpretation, separating endogenous
plasma metabolites from exposure/contaminant/lipid-uncertain annotations, and
supporting robust downstream metabolic biology.

## Proposed Manuscript Structure

1. **Introduction**
   - Challenge of untargeted plasma metabolite annotation.
   - Need for plasma-aware evidence scoring.
   - Distinction between annotation confidence and biological plasma presence.

2. **Methods**
   - Package implementation.
   - Reference database construction.
   - Evidence-tier definitions.
   - Identifier mapping rules.
   - Real-case validation using local `.xlsx` annotation table.

3. **Results**
   - Composition of the reference database.
   - Identifier coverage and ID-only matching.
   - Real-case annotation class distribution.
   - Examples of high-confidence plasma metabolites.
   - Examples of exposure/contaminant/lipid-conservative handling.

4. **Discussion**
   - Strengths of plasma-aware scoring.
   - Serum vs plasma caveats.
   - Xenobiotic interpretation caveats.
   - Lipid annotation limitations.
   - Future updates including Plasma Benchmark full import.

5. **Availability**
   - Public GitHub repository.
   - R package installation instructions.
   - Local real data availability statement.
